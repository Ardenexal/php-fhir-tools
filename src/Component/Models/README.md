# FHIR Models Component

Generated PHP model classes for FHIR resources, data types, primitives, and enums (R4, R4B, R5),
produced by the [CodeGeneration](../CodeGeneration/README.md) component from FHIR StructureDefinitions.

```bash
composer require ardenexal/fhir-models
```
