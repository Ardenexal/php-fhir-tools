# FHIR Code Generation Component

Generates FHIR model classes from StructureDefinitions — PHP classes, data types, primitives, and
enums from FHIR packages — as well as typed extension and profile classes for specific
Implementation Guides.

```bash
composer require ardenexal/fhir-code-generation
```
